# Matriz de evidências para contratação

| Requisito | Evidência no projeto | Evidência externa antes do contrato |
|---|---|---|
| Controle de acesso | RBAC, matrícula, cookie HttpOnly, CSRF, revogação | matriz de perfis homologada pelo cliente |
| Rastreabilidade | `AuditLog`, edição de presença, request ID, logs JSON | retenção, centralização e amostra exportada |
| Segurança | Helmet, rate limit, bcrypt, CodeQL, audit de dependência | pentest e reteste independentes |
| Privacidade | minimização e políticas em docs | RIPD/DPIA, DPO, contratos e inventário aprovado |
| Disponibilidade | probes, restart, runbook, SLO | teste de carga, monitoramento e histórico do piloto |
| Continuidade | volumes, guias e scripts de backup | restauração cronometrada e evidenciada |
| Qualidade | TypeScript, lint, testes, builds e CI | relatório da pipeline da release contratada |
| Acessibilidade | foco, contraste claro, redução de movimento, sem fonte externa | auditoria WCAG 2.2 AA/eMAG com tecnologia assistiva |
| Portabilidade | PostgreSQL, exportação e containers | procedimento de saída, formato e prazo contratual |
| IA responsável | contexto, limites, métricas e política | avaliação pedagógica, segurança e transparência do fornecedor |
| Operação acadêmica | anos, períodos, currículo, turmas, diário, frequência, avaliações e bloqueio de período fechado | homologação de regras de recuperação, conselho e histórico pela rede |
| Família | vínculo explícito, notas somente publicadas, frequência, agenda e horários | validação de responsáveis, consentimentos e política de comunicação |
| Permanência | radar explicável, evidências, acesso restrito e auditoria | avaliação de falsos positivos, equidade e protocolo humano de intervenção |
| Dados governamentais | códigos INEP e relatório de completude cadastral | leiautes vigentes, credenciais e homologação oficial do Educacenso |
| Interoperabilidade | API OpenAPI e exportação auditada alinhada ao OneRoster 1.2 | certificação 1EdTech e teste com o sistema consumidor contratado |

Anexar esta matriz à release e substituir afirmações genéricas por links para artefatos, datas e responsáveis.
